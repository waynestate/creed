# Runtime and headers

The key words MUST, MUST NOT, SHOULD, SHOULD NOT and MAY in this chapter are to be interpreted as described in RFC 2119.

To be decided. No ADR decides the runtime and header rules yet, so this
chapter states no rules.

What is known:

- The runtime (Baseline) is enforcement point (a): it warns, and refuses only
  for unsafe config (the stack's enforcement design).
- The HELMET header work is to be decided.

When the rules are decided, they will land here, with the ADR number that
decided them.
