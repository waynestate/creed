# CREED brand files

**The mark is a stone arch whose gold keystone holds the other stones in place**, because CREED is the
standard everything rests on. The mark itself is serious. The jokes are in the docs.

## Colours
| Role | Colour |
|---|---|
| Tile, background | Wayne State green `#0C5449` |
| Keystone (the only gold) | Wayne State gold `#FFCC33` |
| Stones | Cream `#F4F1EA` |
| Site accent only, never in the mark | Ochre `#634D00` |

Gold never sits behind white text.

## The mark
The mark is a generated raster PNG, approved as a set, not a hand-drawn vector. It is generated by
ChatGPT (an arch with a gold keystone on the green `#0C5449` tile), and it is the only source of the
logo. Use it as provided: don't stretch, recolour, or modify it. `creed-board.png` is the reference:
hero mark, app icon, horizontal and stacked lockups, background applications, the colour palette,
typography (Lato), favicons, clear space, and the do/don't rules.

- Nobody redraws or edits the mark. Logos come only from ChatGPT.
- If a vector is ever needed, trace the PNG with vtracer or potrace. Do not hand-draw it.
