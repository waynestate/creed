# The instance runner[#](https://creed.apps.wayne.edu/docs/guides/instance-runner.html#the-instance-runner)

This page explains why every product in the stack strongly recommends a git.wayne.edu instance runner, and where CREED's code lives until one exists.

## Strongly recommended: a git.wayne.edu instance runner[#](https://creed.apps.wayne.edu/docs/guides/instance-runner.html#strongly-recommended-a-git-wayne-edu-instance-runner)

git.wayne.edu has no runners today. Every product in the stack strongly recommends a git.wayne.edu instance runner.

![Creed Bratton from The Office in a dark suit and blue shirt with a wide, wild-eyed grin](https://creed.apps.wayne.edu/docs/readme/creed-bratton.gif)

Creed Bratton, whose quality assurance work we all admire. His past is a mystery. Ours is in `policy/policy.json`, where it belongs.

## Where the code lives[#](https://creed.apps.wayne.edu/docs/guides/instance-runner.html#where-the-code-lives)

The canonical repository is on nougat: [enterprise-apps/creed](https://nougat.snu.gs/enterprise-apps/creed). git.wayne.edu and GitHub ([waynestate/creed](https://github.com/waynestate/creed)) are read-only mirrors of it. Open issues and merge requests on nougat, not on the mirrors. This moves to git.wayne.edu once it has CI runners.

Creed Bratton would say the code lives wherever he last left it. Ours lives on nougat.
