## §2A.4 Sources

**Every source and note**

The page asks [php-feed.php](https://creed.apps.wayne.edu/php-feed.php), which reads php.net's supported versions, releases and news feed, php-src's tags and the version on its master branch, the php.net wiki's index of release pages and every timetable it lists, endoflife.date and Packagist, and keeps the merge for ten minutes. If that fails, the page reads endoflife.date and php-src's tags straight from your browser and says so. A source that cannot be read is shown as stale or down; nothing on this page is typed in by hand. php.net wins when sources disagree on a date. How long each release is supported is PHP's [release cycle policy](https://wiki.php.net/rfc/release_cycle_update); this page never uses it to guess a date php.net has not published.
